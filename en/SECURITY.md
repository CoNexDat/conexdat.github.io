# Security policy

This repository holds the static source of <https://conexdat.github.io>, built
with Jekyll and served by GitHub Pages. There is no server-side code, database,
or user data.

## Reporting a vulnerability

If you find a problem that could affect visitors (for example a malicious
redirect, leaked secret, or a vulnerable dependency), please report it privately
through GitHub's
[private vulnerability reporting](https://github.com/CoNexDat/conexdat.github.io/security/advisories/new)
rather than in a public issue.

We aim to acknowledge reports within a week. Dependency updates are proposed
automatically by Dependabot.
